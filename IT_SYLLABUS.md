# Lok Sewa Aayog — Computer Officer (कम्प्युटर अधिकृत), Gazetted 3rd Class: IT Syllabus

Full syllabus (7 pages): `computer_officer_syllabus.pdf`. Effective 2080/07/20.
Nepal Miscellaneous Service (नेपाल विविध सेवा), open competition.
This file covers only the IT part, **Paper I Part II: General Technical Subject**. Part I (General Awareness and General Reasoning) is left out.

## Exam scheme (for reference)
| Stage | Paper | Full marks | Pass marks | Format | Time |
|---|---|---|---|---|---|
| Written | Paper I: General Subject | 100 | 40 | Part I: 50 MCQ × 1. Part II (IT): 50 MCQ × 1 | 1 hr 30 min |
| Written | Paper II: Technical Subject | 100 | 40 | Subjective, 10 questions × 10 (short and long answer) | 3 hr |
| 2nd stage | Practical | 50 | 25 | 5 questions × 10 | 1 hr 30 min |
| 2nd stage | Group test | 10 | — | Group discussion | 30 min |
| 2nd stage | Interview | 30 | — | Board interview | — |

- Each wrong MCQ answer loses 20% of its marks (0.2). Unanswered questions score nothing and lose nothing. No calculator.
- The exam can be answered in Nepali, English or both.
- Practical questions: Operating Systems 1, DBMS and Design 2, Programming Language 1, Networking 1.
- The syllabus pages only show the topics for Paper I. The subjective Paper II (Technical Subject) has no separate topic list in these pages, so it is assumed to draw on the same technical topics below.

## Part II: General Technical Subject (50 MCQ). Weight = approximate number of MCQs out of 50.

### 1. Computer Fundamentals (10%, about 5 MCQ)
- 1.1 Computers, kinds of computers by size and function
- 1.2 Generations of computers
- 1.3 Components and architecture of computers, connecting the components
- 1.4 Getting started: personal computers, system unit, starting the computer
- 1.5 Input devices: keyboard, mouse, other input devices
- 1.6 Processing: CPU, memory
- 1.7 Storage devices: floppy disk drive, hard drive, USB devices, other storage
- 1.8 Output devices: monitors, printers, modems, sound boards
- 1.9 DOS survival guide: command prompt, creating and using AUTOEXEC.BAT and CONFIG.SYS
- 1.10 Windows survival guide: desktop, Program Manager, organizing the desktop, File Manager
- 1.11 Using application software
- 1.12 Windows Explorer, e-mail, Internet, intranet, extranet, Ethernet, HTTP
- 1.13 Computer viruses, antivirus

### 2. Data Structure and Algorithms (8%, about 4 MCQ)
- 2.1 Fundamentals of data structures, abstract data types
- 2.2 Lists, linked lists, stacks
- 2.3 Queues, priority queues
- 2.4 Trees: traversal, implementations, binary trees, BST, balanced search trees, AVL trees
- 2.5 Indexing methods, hashing trees, suffix trees
- 2.6 Worst-case and expected time complexity
- 2.7 Analysis of simple recursive and non-recursive algorithms
- 2.8 Searching, merging and sorting
- 2.9 Algorithm design: divide-and-conquer, dynamic programming, greedy methods, backtracking
- 2.10 Graph algorithms: DFS, BFS, shortest path, minimum spanning trees, DAGs

### 3. System Analysis and Design (10%, about 5 MCQ)
- 3.1 System, system owner, user, designers and builders, system analysts, variations on the analyst title, system life cycle
- 3.2 Joint Application Development (JAD): definition, purpose, philosophy, scope
- 3.3 People in a JAD: sponsor, business users, system analyst
- 3.4 Roles of JAD group members: project leader, record keeper, time keeper
- 3.5 System design environment: development process, management process, system structure, components of a computer-based information system, personal/centralized/distributed systems
- 3.6 Concept formation: finding the problem, evaluating the proposal, technical, operational and economic feasibility
- 3.7 Requirements analysis: system analysis model, requirement model, design model
- 3.8 Development process: design method
- 3.9 E-R diagram: notation, strong and weak entities, simple and composite, single- and multi-valued, null and derived attributes
- 3.10 Relationship sets: degree and cardinality, specialization, generalization, aggregation
- 3.11 DFDs: symbols, files or data stores, external entities, data flows
- 3.12 Describing a system with DFDs: context diagram, top-level DFD, expanded-level DFD, conversion of data
- 3.13 Object modeling: OO concepts, object structure, object features, class and object
- 3.14 Representation: association, composition, inheritance, multiple inheritance
- 3.15 Modeling: use case diagram, state diagram, event flow diagram
- 3.16 Documentation: automatic and manual systems

### 4. Operating Systems (10%, about 5 MCQ)
- 4.1 Definition, development and functions of an OS
- 4.2 Basic components of an OS, information storage and management systems
- 4.3 Disk allocation and scheduling, memory management, virtual memory, processes and process management
- 4.4 Process scheduling, inter-process communication, deadlocks
- 4.5 Parallel and distributed processing, security threats to an OS
- 4.6 MS-DOS overview
- 4.7 Windows, Unix and Linux families of products
- 4.8 Windows networking
- 4.9 Windows architecture, Linux architecture
- 4.10 Troubleshooting Windows and Linux
- 4.11 Managing network printing
- 4.12 Managing hard disks and partitions
- 4.13 Monitoring and troubleshooting Windows
- 4.14 Users, groups and permissions in Linux and Windows

### 5. Database Management System and Design (14%, about 7 MCQ)
- 5.1 Introduction, database models, relational model, integrity, RDBMS
- 5.2 SQL and embedded SQL
- 5.3 Basic SQL SELECT statements
- 5.4 Restricting and sorting data
- 5.5 Single-row functions
- 5.6 Displaying data from multiple tables (joins)
- 5.7 Aggregating data with group functions
- 5.8 Subqueries, manipulating data, creating and managing tables
- 5.9 Views and controlling user access
- 5.10 Set operators, date-time functions
- 5.11 Database design: logical, conceptual, mapping conceptual to logical, pragmatic issues, physical design, integrity and correctness, relational algebra, relational calculus
- 5.12 Normalization: 1NF, 2NF, 3NF, BCNF, 4NF, 5NF, DKNF
- 5.13 DBMS architecture: client-server, open architectures, transaction processing, multi-user and concurrency, backup and recovery
- 5.14 Major RDBMS products: Oracle, Sybase, DB2, SQL Server and others

### 6. Programming Language (8%, about 4 MCQ)
- 6.1 History, programming paradigms, role of language translators
- 6.2 Fundamental issues in language design
- 6.3 Virtual machines, code generation, loop optimization
- 6.4 Procedural, structured and object-oriented programming
- 6.5 C and C++ programming
- 6.6 Java: declaration, modularity and storage management

### 7. Networking (10%, about 5 MCQ)
- 7.1 Basic theory: definition, network models, connectivity, addressing
- 7.2 Connectivity: data packets, establishing a connection, reliable delivery, noise control, building codes, connection devices
- 7.3 Advanced theory: OSI model, Ethernet, network resources, Token Ring, FDDI, wireless
- 7.4 Protocols: protocol families, NetBEUI, bridges and switches, TCP/IP, building a TCP/IP network, TCP/IP suite
- 7.5 TCP/IP services: DHCP, DNS, NetBIOS support, SNMP, TCP/IP utilities, FTP
- 7.6 LAN infrastructure: LAN protocols, IP routing, routing tables, router discovery protocols, data movement in routed networks, VLANs
- 7.7 WAN infrastructure: WAN environment, transmission technologies, connectivity devices, voice over data
- 7.8 Remote networking: remote access protocols, VPN
- 7.9 Computer security: virus, worm, Trojan horse
- 7.10 Network security: virus protection, local security, network access, Internet security
- 7.11 Disaster recovery: need, recovery plan, data backup, fault tolerance
- 7.12 Advanced storage: enterprise storage, clustering, NAS, SAN
- 7.13 Network troubleshooting: systematic approach
- 7.14 Network support tools: utilities, network baseline
- 7.15 Network access points, common network components, common peripheral ports

### 8. Computer Architecture & Organization (4%, about 2 MCQ)
- 8.1 Evolution of computers, design methodology, instruction set architecture, MIPS ISA, ALU design
- 8.2 Datapath design: single- and multi-cycle, pipelining, memory hierarchy, I/O system, buses and the role of the OS

### 9. Compiler Design (2%, about 1 MCQ)
- 9.1 Introduction to compiling
- 9.2 Lexical, syntax and semantic analysis
- 9.3 Run-time environment
- 9.4 Intermediate code generation, code optimization
- 9.5 Compiler generation tools

### 10. E-Commerce Technology (4%, about 2 MCQ)
- 10.1 Introduction to e-commerce
- 10.2 E-commerce strategies
- 10.3 E-commerce security issues
- 10.4 Success models of e-governance
- 10.5 E-business: B2B, B2C, B2E, C2C, G2G, G2C
- 10.6 Electronic payment principles, strategies and systems
- 10.7 E-marketing, reverse engineering
- 10.8 E-banking, EDI methods, SWIFT
- 10.9 Encryption and decryption, XML, layout managers, event model

### 11. MIS and Web Engineering (10%, about 5 MCQ)
- 11.1 Information systems, client-server computing
- 11.2 Information systems and decision making
- 11.3 Database design issues, data mining, data warehousing
- 11.4 Knowledge management, strategic use of IT
- 11.5 Reengineering with IT, ERP, IS security, information privacy, global IT issues
- 11.6 Software demonstrations including advanced spreadsheets, CBSE
- 11.7 Multimedia
- 11.8 OOP with COM and DCOM
- 11.9 Group decision support systems
- 11.10 Basics of website design

### 12. IT in Nepal (10%, about 5 MCQ)
- 12.1 History of IT in Nepal
- 12.2 IT policy of Nepal
- 12.3 Electronic Transaction Act
- 12.4 Copyright Act
- 12.5 Uses of computers and software development
- 12.6 Nepali Unicode, Nepali fonts
- 12.7 Licensing issues

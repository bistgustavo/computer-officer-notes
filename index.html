Suggested study order

  • Start with the heaviest units: DBMS (14%) → Computer Fundamentals (10%) → System Analysis and Design (10%) → Operating Systems (10%) → Networking (10%) → MIS and Web Engineering (10%) → IT in Nepal (10%).
  • In each chapter read the syllabus map and past questions first, then the content, then write the model answers from memory.
  • Do each chapter's MCQ bank without looking, then check the answer key at the end of the PDF; use the quick-revision sheet the night before.
  • Practical exam: OS 1, DBMS 2, programming 1 and networking 1. Work through the practical sections of Chapters 4, 5, 6 and 7 by hand.

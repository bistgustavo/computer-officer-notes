Suggested study order

  • Start with the heaviest units: DBMS (14%) → Computer Fundamentals (10%) → System Analysis (10%) → Operating Systems (10%) → Networking (10%) → MIS (10%) → IT in Nepal (10%).
  • Read the main notes first, then the CO supplement for the same unit.
  • Do each PDF's MCQ bank without looking, then check the answer key at the end of the PDF.
  • Practical exam: OS 1, DBMS 2, programming 1 and networking 1. Practise SQL, Linux/Windows commands, a C/C++/Java program and network commands by hand.
